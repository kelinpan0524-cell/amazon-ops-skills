# amz-listing-audit

> 每周体检 Listing 时用：先查 OE 号与年款适配，再查标题/五点/主图，缺的数标待补。

| --- | --- |

| 有脚本 | 是 |

## 数据源

sales_daily 的 product_name 当标题（领星自动带）；listing_current 可选补充五点/A+/图数

## 逻辑链路（这是怎么算出来的）

① CDQ 框架六维加权（参考开源 amazon-listing-doctor）：结构化属性 30%/标题 25%/变体 20%/图片 15%/五点 5%/A+ 5%

② 标题四查：长度（移动端 75 字符截断提醒）/绝对化用语（亚马逊下架词）/COSMO 意图四要素（场景/适配/解决什么/限制）/车型品牌（汽配命门）

③ 汽配命门独立一节：OE 号/年款/车型填写率（有 sku_master 才查）

④ 车标 HOLD：标题命中车标触发词 = 侵权硬阻断（图片允许品牌名文字允许，车标图形绝不允许）

⑤ 查不了的维度标『未检查』不给 0 分也不给满分——假装查过比不查更糟
