# amz-store-daily

> 单店铺经营日报（HTML 图表版）：按店铺组出销售额趋势、销量、ACOS、库存卡片的单文件报告，供IM归档与工作台展示。

| | |
| --- | --- |
| 类型 | 报告与复盘（自动） |
| 运行 | 每天 06:15（每店一份） |
| 有脚本 | 是 |

## 数据源

shop_daily 单店 + benchmarks 历史基线

## 逻辑链路（这是怎么算出来的）

① 单店 KPI+近 30 天趋势图+库存卡

② 带基准对照（KPI note 显示历史分位，判断今天好坏是跟自己过去比）

## 为什么这样设计 / 阈值依据

分店版有 SKU 明细、总览版只有店级——两份独立文件不是一份加筛选，因为看的人不同、详略不同。

## 输出去向

data/reports/shop/<店>/ → 云盘；运营看自己那份

## 怎么调

--shop shop_a 指定店
