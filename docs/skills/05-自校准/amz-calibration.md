# amz-calibration

> 每周日复盘时用：把到期判断拉出来对账，算技能命中率，低了就降权。

| | |
| --- | --- |
| 类型 | 系统自校准（自动） |
| 运行 | 每周日 20:00 |
| 有脚本 | 是 |

## 数据源

judgements/ 目录（每次技能输出建议时落的判断卡，带 expected 和 review_on）

## 逻辑链路（这是怎么算出来的）

① 拉到期待复核的判断

② 对账：预期 vs 实际，算命中率

③ 命中率低的建议降权/调阈值——这是整个系统自迭代的闭环

## 为什么这样设计 / 阈值依据

这是系统自迭代的闭环：技能每次输出建议时落判断卡（expected+review_on），到期对账命中率，低了降权——没有这个，所有阈值都是拍的。

## 输出去向

校准报告（建议哪些阈值要调）
