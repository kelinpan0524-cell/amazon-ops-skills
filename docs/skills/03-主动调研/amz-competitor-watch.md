# amz-competitor-watch

> 竞品与跟卖监控（卖家精灵 MCP）：盯 5–10 个同货架 ASIN 的价格/评分/评论/BSR/卖家数变化，发现跟卖嫌疑，只报变化不抓页面。

| | |
| --- | --- |
| 类型 | 主动调研 |
| 运行 | 周五 17:00（默认关，名单没填不开） |
| 有脚本 | 是 |

## 数据源

卖家精灵 asin.detail（竞品快照）+ 上次快照对比

## 逻辑链路（这是怎么算出来的）

① 盯 profiles/competitors.md 的 5-10 个同货架 ASIN

② 只报变化不报绝对值：降价>8%（抢单）/提价>8%（留空间）/评论暴增 30（在推）/评分掉 0.2（出问题）/卖家数增加（跟卖嫌疑）

## 为什么这样设计 / 阈值依据

只报变化不报绝对值：绝对值天天看没感觉，变化才是信号。降价 8% 是抢单开始的实测经验线。
