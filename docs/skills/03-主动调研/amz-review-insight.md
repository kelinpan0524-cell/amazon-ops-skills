# amz-review-insight

> 竞品差评分析（主动型）：拉竞品的 1-3 星评论，按「装不上/尺寸/质量/物流/描述不符/价格/安装难」归类，每一类给出「你能怎么用」——从别人的客诉里找选品和改款机会。

## 数据源

卖家精灵 asin.review.list（竞品的 1-3 星评论）

## 逻辑链路（这是怎么算出来的）

① 拉竞品评论（ASIN 来自 profiles/competitors.md 或命令行传）

② 关键词归类七类（英文正则，顺序有意义——最具体的先判）：装不上/尺寸/质量/物流/描述不符/价格/安装难

③ 每类给『你能怎么用』：装不上→它 fitment 烂你做装得上的同款直接吃客诉流量；质量→查具体哪里坏在那处加成本

④ 归类靠正则不是大模型：中文评论和反讽会归错，报告里明说『抽样读几条确认』

⑤ 21 项断言钉住归类（归错方向会反：把装不上误判成质量差，结论从快上变成有门槛）

## 为什么这样设计 / 阈值依据

竞品差评是免费的选品调研——200 条评论 40 条说装不上的品，你做装得上同款就能抢客。参考 nexscope amazon-review-analyzer 等开源做法：都按问题类型归类而非罗列。
