# amz-brand-analytics

> 品牌分析（主动型）：看一个品牌在亚马逊上的盘子——有多少 ASIN 在卖、销量怎么分布、在类目里占多少份额、新品起没起来；也能用来盯竞争对手的品牌整体动向。

## 数据源

卖家精灵 asin.list（按品牌筛）+ asin.sales.trend + category.top.list

## 逻辑链路（这是怎么算出来的）

① 品牌下全部在售 ASIN（品牌名要亚马逊写法不是中文名）

② Top1 集中度：>50% = 单点依赖（那个款被跟卖/断货品牌就崩 = 机会）

③ 新品占比：半年内上架 ASIN 的销量占比，低 = 吃老本

④ 类目份额：不在 Top20 = 主战场不在这

⑤ 最有价值用法：竞品品牌盘子 vs 我们多店合计 → 差距在上新节奏还是 SKU 密度

## 为什么这样设计 / 阈值依据

Top1 集中度和新品占比比总销量更能判断品牌会不会掉——单点依赖+吃老本 = 它的今天是虚的。
