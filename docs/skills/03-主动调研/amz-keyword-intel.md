# amz-keyword-intel

> 关键词与市场情报调研（卖家精灵 MCP）：关键词搜索量/竞争度/PPC、竞品 ASIN 分析、类目趋势，输出选词与选品的结构化调研报告。

| | |
| --- | --- |
| 类型 | 主动调研 |
| 运行 | 运营手动（按次计费 3-10 次/调研） |
| 有脚本 | 否（流程型，AI 按 SKILL.md 编排） |

## 数据源

卖家精灵 keyword.related.list（词找词）/ keyword.asin.list（品找词）/ keyword.aba.list（ABA 排名）

## 逻辑链路（这是怎么算出来的）

① 三条路：查词（搜索量/竞争度/PPC）→ 扩词（相关词）→ 反查（竞品出单词）

② 省额度三招：默认 size=10；先批量快照再对入选词拉趋势；已知 ASIN 品找词优于凭空词找词

## 为什么这样设计 / 阈值依据

三条路对应三种问题：查词（这个词值不值得做）→ 扩词（还有哪些相关词）→ 反查（竞品靠什么词出单）。

## 输出去向

结构化调研报告
