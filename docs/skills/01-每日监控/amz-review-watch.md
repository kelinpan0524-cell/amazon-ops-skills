# amz-review-watch

> 评论监控（我们自己的 ASIN）：每天看有没有新评论，重点抓 1-3 星差评——那是产品问题的第一信号；只报新出现的，不重复报老评论。

| | |
| --- | --- |
| 类型 | 每日监控（自动） |
| 运行 | 每 3 天 06:50（评论不是天天有，晚两天不影响处理） |
| 有脚本 | 是 |

## 数据源

卖家精灵 asin.review.list（标准版 100 条/ASIN；extended 500 条太慢太贵不看）

## 逻辑链路（这是怎么算出来的）

① 拉名单内 ASIN（profiles/hijack-watch.md，自动按销售额填 Top20）最近评论

② 去重：键 = 日期 + 标题前 40 字（评论没有稳定 ID；不去重会天天报同一批老差评，人直接无视）

③ 1-3 星单独挑出（汽配 1-2 星多是装不上/尺寸不对 = fitment 数据错了，压着看会变退货）

④ 每个 ASIN 拉完立刻落盘（曾卡在第 20 个请求上前 19 个全丢）

⑤ 快照自动同步外部表格「评论监控」表

## 为什么这样设计 / 阈值依据

星级解析失败给 None 不是 0——0 会被误判成零星差评。实测首跑：118 条评论 7 条差评，3 条『装不上』指向 fitment 问题。

## 输出去向

data/reports/review/ + 外部表格；退出码 1 = 有新差评

## 怎么调

BAD_STAR_MAX=3 / FETCH_LIMIT=20 在脚本顶部
