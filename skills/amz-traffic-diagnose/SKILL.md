# 流量诊断

"这个品卖不动"有很多原因，最常见的是**流量结构有问题**。这个技能把三件事分开说：

| 症状 | 说明什么 | 该做什么 |
| --- | --- | --- |
| 前 3 词占流量 >60% | 太依赖少数词，任何一个掉排名就断崖 | 补长尾词 |
| 自然词只有 1-2 个 | 全靠广告，广告一停就没流量 | 做关键词布局（五点/描述/A+） |
| 高曝光低转化 | **不是流量问题**，是图片/价格/评分接不住 | 修 listing，先别加广告预算 |


## 交互协议（主动调用时：先问清，再执行）

本技能是**主动式**技能。被调用时不要直接闷头跑脚本：先核对下面的前置信息，
缺哪项就**用带选项的问题**一次问清（一次最多 3 个问题，能合并就合并），拿到答案再执行。

| 前置信息 | 为什么需要 | 选项 / 默认值 |
|---|---|---|
| 诊断对象 | 店铺还是具体 ASIN | 选项：店铺整体（默认）/ 指定 ASIN（需用户提供列表） |
| 时间窗与对比基准 | 环比/同比结论完全不同 | 默认近 7 天环比；可选近 30 天、同比 |
| 是否下钻关键词 | 决定要不要调关键词数据 | 选项：需要（默认，流量异常时）/ 不需要 |

多轮对话规则：
1. 用户后续补充或修改口径时，以**最新一轮**为准，并复述确认关键参数（范围/对象/阈值）。
2. 信息齐全后先用一句话复述「我要用什么对象 + 什么时间窗 + 什么阈值 + 输出什么」，再动手。
3. 缺数据/缺密钥时直说并给替代路径，**不编数**；外部写操作（发消息、写外部表格、改广告）必须显式确认。
4. 用户只想快速要结果时，可直接采用上表默认值，但要在开头列出所用默认值。

## 判读规则（脚本里的阈值）

- **前 3 词占流量 >60%** → 标"过度依赖少数词"
- **自然词 ≤2 个** → 标"广告一停就死"
- **搜索量在前 40% 但购买率低于中位 50%** → 高曝光低转化

## 跟其他技能的分工

- 想知道**某几个词**的搜索量/竞价 → `amz-keyword-intel`
- 想判断**这个类目**能不能进 → `amz-product-research`
- 想知道**Listing 文字**有没有问题 → `amz-listing-audit`

## 口径

1. 搜索量/购买率都是**卖家精灵估算**，只能横向比
2. 流量词来自卖家精灵词库，**未收录的 ASIN 返回空**（不代表真的没流量）
3. 「高曝光低转化」是**相对该 ASIN 自己中位购买率**判的，不是绝对标准
